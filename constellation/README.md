# Interactive Force-Graph – Konstelacja

Live dual-mode (Ordo ↔ Nigredo) force-directed graph for the Individuation Chamber.

## How to run

Open `index.html` directly in a modern browser (or serve the folder).

The full interactive prototype lives in the project artifacts / constellation folder and will be integrated into the Next.js site.

## Features

- Dual mode: Ordo (clean neon) / Nigredo (organic crimson)
- Trząść detection (rapid mouse movement) + explicit button
- Click nodes for chamber info + links to Gamma pages
- Central Self/Void + Wstydosfera + technical agents + Shadow complexes
- Theme Constitution colors locked for Ordo

See also: CONSTELLATION.md and Dual_Path_Ordo_Nigredo_Architecture.md
